# Password Generator

A simple web-based password generator built with HTML, CSS (Bootstrap), and JavaScript.


## Features

- Generate random passwords of customizable length (6-50 characters)
- Includes uppercase letters, lowercase letters, numbers, and special characters
- Copy generated password to clipboard
- Responsive design using Bootstrap

## Usage

1. Open `Password Generator.html` in your web browser.
2. Enter the desired password length (between 6 and 50).
3. Click "GET PASSWORD" to generate a new password.
4. Click "COPY" to copy the password to your clipboard.

## Technologies Used

- HTML5
- CSS3 (Bootstrap 5.3.0)
- JavaScript (ES6)
